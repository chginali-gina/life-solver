# 生活觀察解題室

鳳新高中自主學習工具：引導學生從生活觀察中找出問題，選擇初階到進階的實作方案，並記錄執行過程與成果。

## 老師設定（index.html 最上方）

- `SCRIPT_URL`：Google Apps Script 網頁應用程式網址（結尾 `/exec`）
- `GOOGLE_CLIENT_ID`：Google OAuth 用戶端 ID；填入後只有 `@fhsh.khc.edu.tw` 帳號能登入使用
- `ALLOWED_DOMAIN`：允許的學校網域

後台程式（Code.gs）不放在這個公開的 repository，請保存在 Google 試算表的 Apps Script 中。
